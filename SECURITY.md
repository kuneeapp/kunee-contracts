# Security for KUNEE Contracts

## Scope and status

This sample-only repository contains documentation, not contract source. Its deployment record describes an operator-only rehearsal on Robinhood Chain (chain ID `4663`), not a public release or an invitation to deposit public funds. The rehearsal pool restricts `Shield` to its deployer. No security guarantee or production readiness is implied.

The browser lab is a separate ephemeral local chain (chain ID `31337`) with no public mainnet access.

## Reporting a security concern

Please avoid posting potentially exploitable details or sensitive information in a public issue. Send a concise report to [support@kunee.app](mailto:support@kunee.app), with the affected component or documentation and safe reproduction information where possible.

Never send or publish secrets, wallet private material, recovery phrases, private keys, or credentials. Do not include real user data.

## Verification caution

The addresses and transaction identifiers in [DEPLOYMENTS.md](DEPLOYMENTS.md) are recorded rehearsal facts. Explorer links are provided for lookup; they do not establish verified source code, an independent audit, or a public release. Consult the internal release record and independently confirm chain details before relying on any information.
