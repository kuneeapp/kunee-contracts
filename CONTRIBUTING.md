# Contributing to KUNEE Contracts

Thank you for helping maintain accurate and responsible contract documentation. This sample-only repository contains documentation, not contract source or a deployable contract package.

By contributing, you agree to license your contributions to this repository under its [MIT License](./LICENSE). Only contribute work you have the right to license; this does not license the KUNEE application or its trademarks.

## Contribution principles

- Keep documentation precise and distinguish observed rehearsal facts from plans, assumptions, and unresolved release gates.
- Check deployment facts against KUNEE's internal release record before editing them.
- Preserve the operator-only and non-public-release warnings wherever rehearsal deployments are discussed.
- Never add secrets, wallet private material, recovery phrases, private keys, credentials, or personal data.
- Do not add real application or contract source to this documentation-only sample folder.

## Proposing a change

Explain the purpose of the change and cite the authoritative record for any altered network, address, transaction, or parameter. Avoid implying source verification, independent review, public availability, or production readiness unless an authoritative release record explicitly establishes it.
